Find answers to the most frequently asked questions about ScatterBrain below. If your question isn't covered here, check the Troubleshooting guide or reach out to support.

<AccordionGroup>
  <Accordion title="Does ScatterBrain work with all documentation sites?">
    No, ScatterBrain is built specifically for Atlas-hosted documentation sites. Docs on other platforms (GitBook, Confluence, Notion, etc.) are not currently supported. See the Supported Sites guide for details.
  </Accordion>

  <Accordion title="Do I need to create an account to use ScatterBrain?">
    No account is required to export documentation to PDF. Simply navigate to scatterbrain.com, paste a URL, and export.
  </Accordion>

  <Accordion title="How long does an export take?">
    Export time depends on the size of the documentation site. Small sites (under 20 pages) typically complete in under 30 seconds. Larger sites with 100+ pages may take 2–3 minutes.
  </Accordion>

  <Accordion title="Is there a limit on the number of pages I can export?">
    ScatterBrain can export documentation sites of any size. For very large sites (200+ pages), export times will be longer but there is no hard page cap.
  </Accordion>

  <Accordion title="Why is my documentation not recognized as an Atlas site?">
    ScatterBrain detects Atlas sites by their structure. If your site is private, behind a login, or hosted on a different platform, it will not be recognized. Confirm the site is publicly accessible and built on Atlas.
  </Accordion>

  <Accordion title="Can I export documentation that requires a login?">
    No. ScatterBrain can only export publicly accessible documentation. Password-protected or auth-gated docs are not supported.
  </Accordion>

  <Accordion title="What browsers does ScatterBrain support?">
    ScatterBrain works in all modern browsers including Chrome, Firefox, Safari, and Edge. We recommend using the latest version for the best experience.
  </Accordion>

  <Accordion title="Will the PDF include images?">
    Yes, images embedded in the documentation are included in the exported PDF at their original resolution.
  </Accordion>

  <Accordion title="Can I re-export the same site to get updated docs?">
    Yes. Each export captures the documentation as it exists at export time. To get the latest version of any documentation site, simply run a new export.
  </Accordion>

  <Accordion title="What format is the downloaded file?">
    ScatterBrain exports a standard `.pdf` file compatible with any PDF reader.
  </Accordion>
</AccordionGroup>
