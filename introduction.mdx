ScatterBrain is a browser-based tool that takes an Atlas documentation URL, crawls every page in the site, and bundles them into a single, well-formatted PDF file. There's nothing to install and no account to create — open the tool, paste your URL, and export. ScatterBrain handles discovery, rendering, and assembly entirely in your browser, delivering a complete PDF in sidebar order with all formatting preserved.

## What You Can Do with ScatterBrain

ScatterBrain is built for anyone who needs documentation outside of a live web browser. Common use cases include:

- **Save documentation offline** — Read complete doc sets without an internet connection, whether you're traveling, on-site, or working in a restricted environment.
- **Share a snapshot with teammates** — Distribute a consistent, point-in-time version of documentation to colleagues without sending links that may change.
- **Archive documentation** — Capture documentation exactly as it appears today and store it for compliance, auditing, or long-term reference.
- **Print physical copies** — Generate print-ready PDFs of technical references, API guides, or onboarding materials for workshops and meetings.
