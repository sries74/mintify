ScatterBrain converts Atlas documentation to PDF in three quick steps. No account needed — open the tool, paste a URL, and download. From start to finish, most exports complete in under a minute.

<Steps>
  <Step title="Open ScatterBrain">
    Navigate to [scotterbrain.com](https://scotterbrain.com) in your browser. No sign-in or installation is required.
  </Step>
  <Step title="Paste Your Docs URL">
    Enter the URL of any Atlas documentation site (e.g., `https://docs.example.com`) into the input field. ScatterBrain will validate the URL and detect the documentation structure, identifying every page available for export.
  </Step>
  <Step title="Export to PDF">
    Click the **Export PDF** button. ScatterBrain crawls every page in the documentation and bundles them into a single file. When complete, your PDF will download automatically to your device.
  </Step>
</Steps>

<Tip>
  For large documentation sites, the export may take a minute or two. You can see live progress as each page is captured.
</Tip>

## What Happens Next

Once the export is complete, your browser will download a single PDF file containing the entire documentation site. The PDF is assembled in sidebar order — the same sequence you'd navigate on the live site — so the structure feels familiar from the first page.

Inside the PDF you'll find:

- A **table of contents** generated from the documentation's navigation structure.
- All **headings, subheadings, prose, code blocks, tables, and images** rendered as they appear in the browser.
- **Internal links** converted to PDF bookmarks, so you can jump between sections without scrolling.
